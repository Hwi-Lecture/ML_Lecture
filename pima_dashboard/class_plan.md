# Pima Indians 데이터로 배우는 머신러닝 & AI 대시보드 만들기 (총 1일 / 총 8h)

## 기본 전제
- 대상: 비개발자 수강생, 각자 노트북 지참 (AI 코딩 에이전트 설치/로그인 여부 미확정)
- 목표: 수강생이 직접 AI 에이전트와 대화하며 EDA → 전처리 → 모델 비교 → 대시보드까지 스스로 완성
- 강사가 이미 만든 완성본 대시보드는 "정답 공개용 데모"로만 짧게 보여주고, 수강생 실습 폴더에는 넣지 않음

## 진행 팁

- **완성 대시보드(`pima_dashboard/app.py`)는 수강생에게 통째로 주지 않기.** 그대로 열어보게 하면 "이미 다 있네요"로 끝나버려서, 직접 프롬프트로 설계해보는 실습 목적이 사라집니다. 시연용으로 1~2분만 보여주고, 수강생은 빈 폴더(데이터 파일만 있는 폴더)에서 시작하게 하세요.
- **실습 폴더와 안내문을 분리하세요.** 수강생이 AI 에이전트에게 열어줄 작업 폴더에는 `data/diabetes.csv`처럼 원본 데이터만 두고, "이런 상황이니 이런 대시보드를 만들어보세요" 같은 시나리오/요구사항은 별도의 슬라이드나 워크시트(작업 폴더 밖)에 둡니다. 안내문이 작업 폴더 안에 `readme.md`처럼 들어가 있으면 AI가 그걸 지시서로 읽고 수강생 대신 다 만들어버릴 수 있습니다.
- **프롬프트를 단계별로 유도**: "데이터를 요약해줘" → "이상한 값 처리해줘" → "모델 두 개 비교하는 화면 만들어줘" → "기능 하나 더 추가해줘" 순으로 난이도를 올리면, 급하게 완성본을 요구하지 않고 대화형 개발 흐름 자체를 체감할 수 있습니다.
- **환경 세팅 리스크 대비**: 세팅이 미확정이므로 오전 30분 안에 설치가 끝나지 않는 인원을 위해 백업으로 온라인 실행 환경(예: 이미 세팅된 예비 노트북 1~2대, 또는 클라우드 실습 환경)을 준비해두는 걸 권장합니다.
